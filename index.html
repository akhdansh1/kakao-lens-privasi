Kebijakan Privasi

Kakao Lens

Berlaku sejak 25 November 2026 · Versi aplikasi 0.6.0

Ringkasan
  • Pengguna masuk dengan akun Google. Aplikasi tidak lagi memakai PIN maupun nomor HP.
  • Analisis foto buah kakao dilakukan sepenuhnya di perangkat dan tetap berjalan tanpa internet.
  • Data akun, data kebun, riwayat pemeriksaan beserta fotonya, dan catatan perawatan disimpan di perangkat dan disalin ke server Kakao Lens, agar data tidak hilang dan dapat dibuka kembali di perangkat lain dengan akun Google yang sama.
  • Data tidak dijual, tidak dibagikan untuk iklan, dan aplikasi tidak memuat iklan, analitik, atau pelacak pihak ketiga.
  • Akun dan seluruh datanya di server dapat dihapus kapan saja melalui Akun → Hapus akun, atau melalui permintaan penghapusan akun.

1. Tentang aplikasi ini

Kakao Lens adalah aplikasi Android untuk membantu petani memeriksa kesehatan buah kakao dari foto. Aplikasi dikembangkan oleh Akhdan Shalahudin, mahasiswa Institut Teknologi Sains Bandung, sebagai bagian dari proyek akademik. Hasil analisis merupakan alat bantu, bukan diagnosis pasti; keputusan pengendalian sebaiknya dikonfirmasi bersama petugas lapangan.

2. Masuk dengan akun Google

Untuk memakai aplikasi, Anda masuk dengan akun Google melalui fitur masuk bawaan Android. Dengan persetujuan Anda pada layar Google, aplikasi menerima nama, alamat email, dan foto profil akun Google Anda.

  • Alamat email dan pengenal akun Google disimpan di server sebagai identitas akun Anda.
  • Nama dipakai untuk mengisi awal kolom nama saat mendaftar; Anda dapat mengubahnya.
  • Foto profil tidak dipakai dan tidak disimpan.

Kata sandi Google Anda tidak pernah diterima oleh aplikasi maupun server kami. Server memeriksa keabsahan tanda masuk dari Google, lalu memberikan sesi yang berlaku 30 hari. Setelah sesi berakhir, aplikasi tetap dapat dipakai; penyalinan ke server berhenti sampai Anda masuk kembali.

3. Data yang disimpan

Data berikut dibuat oleh Anda saat memakai aplikasi. Semuanya disimpan lebih dahulu di perangkat, lalu disalin ke server Kakao Lens di latar belakang ketika perangkat terhubung ke internet.

4. Server dan pihak yang terlibat

  • Server Kakao Lens dikelola oleh pengembang dan berada di Indonesia, dengan alamat api.kakaolens.my.id. Satu akun tidak dapat membaca data akun lain. Pengembang dapat melihat data yang tersimpan di server (termasuk foto dan hasil pemeriksaan) hanya dari perangkat server itu sendiri, untuk keperluan pemeliharaan layanan dan penelitian akademik dalam rangka tugas akhir; data tidak dibagikan kepada pihak lain.
  • Cloudflare meneruskan koneksi antara aplikasi dan server. Seluruh koneksi dienkripsi (HTTPS) selama pengiriman.
  • Google menyediakan fitur masuk dengan akun Google dan memeriksa keabsahan tanda masuk.
  • Open-Meteo menerima koordinat kebun yang telah dibulatkan ke dua angka desimal (ketelitian sekitar 1 km) bila fitur cuaca aktif dan titik kebun telah diisi. Permintaan ini tidak menyertakan nama, email, foto, maupun data lain; penanganannya mengikuti ketentuan Open-Meteo. Fitur cuaca dapat dimatikan melalui Akun → Pengaturan → Cuaca di Beranda.

Seperti layanan internet pada umumnya, server mencatat log teknis berupa alamat IP, waktu, dan alamat permintaan untuk keperluan keamanan dan penanganan gangguan. Log ini tidak berisi foto maupun isi data Anda dan ditimpa secara berkala.

6. Berbagi dan menyimpan foto hasil

Selain disalin ke server akun Anda, foto hasil analisis hanya keluar dari aplikasi bila Anda sendiri menekan Simpan (foto disimpan ke galeri perangkat) atau Bagikan (Anda memilih aplikasi tujuan, misalnya WhatsApp). Setelah dibagikan, foto tunduk pada kebijakan aplikasi tujuan yang Anda pilih.

7. Yang tidak kami lakukan

  • Tidak menjual data atau membagikannya kepada pihak ketiga untuk iklan maupun tujuan lain.
  • Tidak menampilkan iklan dan tidak memakai layanan analitik atau pelacakan.
  • Tidak melacak lokasi di latar belakang.
  • Tidak memakai foto atau data Anda untuk melatih model tanpa persetujuan terpisah dari Anda.

8. Keamanan

Di perangkat, data disimpan di area penyimpanan khusus aplikasi yang tidak dapat dibaca oleh aplikasi lain. Koneksi ke server dienkripsi (HTTPS), dan server hanya dapat diakses melalui sesi akun yang sah. Karena aplikasi langsung terbuka setelah masuk, jaga kunci layar perangkat Anda.

9. Keluar dan menghapus data

  • Akun → Keluar menghapus seluruh data akun dari perangkat ini. Salinan di server tetap ada, sehingga data kembali saat Anda masuk lagi dengan akun Google yang sama. Bila masih ada data yang belum tersalin, aplikasi memberi peringatan terlebih dahulu.
  • Akun → Hapus akun menghapus akun beserta seluruh data di server (data akun, data kebun, riwayat, foto, kunjungan, dan catatan), kemudian menghapus data dari perangkat ini. Penghapusan di server dilakukan seketika dan tidak dapat dibatalkan.
  • Riwayat pemeriksaan dapat dihapus satu per satu dari layar hasil pemeriksaan; penghapusan ikut tersalin ke server.
  • Bila aplikasi sudah tidak terpasang, penghapusan akun dapat diminta melalui halaman Permintaan penghapusan akun.

Data disimpan di server selama akun masih ada. Foto yang sebelumnya Anda simpan ke galeri atau bagikan ke aplikasi lain tidak ikut terhapus.

10. Anak-anak

Aplikasi ini ditujukan bagi petani dan petugas pertanian dewasa, dan tidak ditujukan untuk anak-anak.

11. Perubahan kebijakan

Kebijakan ini dapat diperbarui bila fitur aplikasi berubah. Versi terbaru selalu tersedia di halaman ini, dengan tanggal berlaku di bagian atas. Versi 0.6.0 menggantikan versi sebelumnya yang menyatakan bahwa aplikasi tidak memiliki server.
