Kebijakan Privasi

Kakao Lens

Berlaku sejak 22 November 2026 · Versi aplikasi 0.3.0

Ringkasan
  • Analisis foto buah kakao dilakukan sepenuhnya di perangkat. Foto tidak pernah dikirim ke server mana pun.
  • Data akun (nama, nomor HP, data kebun) dan PIN hanya disimpan di perangkat Anda. Kami tidak memiliki server dan tidak dapat melihat data tersebut.
  • Satu-satunya data yang keluar dari perangkat adalah perkiraan lokasi kebun (dibulatkan sekitar 1 km) untuk mengambil prakiraan cuaca, dan fitur ini dapat dimatikan.
  • Aplikasi tidak memuat iklan, analitik, atau pelacak pihak ketiga.

1. Tentang aplikasi ini

Kakao Lens adalah aplikasi Android untuk membantu petani memeriksa kesehatan buah kakao dari foto. Aplikasi dikembangkan oleh Akhdan Shalahudin, mahasiswa Institut Teknologi Sains Bandung, sebagai bagian dari proyek akademik. Hasil analisis merupakan alat bantu, bukan diagnosis pasti; keputusan pengendalian sebaiknya dikonfirmasi bersama petugas lapangan.

2. Data yang disimpan di perangkat Anda

Data berikut dibuat oleh Anda saat memakai aplikasi dan disimpan di penyimpanan internal aplikasi pada perangkat Anda. Data ini tidak dikirim kepada kami maupun pihak lain.

3. Izin yang diminta

IzinAlasan
KameraMemotret buah kakao langsung di aplikasi. Tanpa izin ini, foto tetap dapat dipilih dari galeri.
Lokasi (perkiraan dan akurat)Mengambil titik kebun satu kali, atas perintah Anda. Bersifat opsional.
InternetHanya untuk mengambil prakiraan cuaca (lihat bagian 4). Analisis foto tidak memerlukan internet.

Pemilihan foto dari galeri memakai pemilih foto bawaan Android, sehingga aplikasi hanya dapat membaca foto yang Anda pilih dan tidak memerlukan izin akses ke seluruh penyimpanan.

4. Data yang dikirim keluar dari perangkat

Jika fitur cuaca aktif dan titik kebun telah diisi, aplikasi mengirim koordinat kebun yang telah dibulatkan ke dua angka desimal (ketelitian sekitar 1 km) ke layanan prakiraan cuaca Open-Meteo. Permintaan ini tidak menyertakan nama, nomor HP, foto, maupun data lain. Seperti setiap koneksi internet, alamat IP perangkat Anda dapat terlihat oleh penyedia layanan tersebut; penanganannya mengikuti ketentuan Open-Meteo.

Fitur cuaca dapat dimatikan kapan saja melalui Akun → Pengaturan → Cuaca di Beranda. Setelah dimatikan, aplikasi tidak membuka koneksi internet sama sekali.

5. Berbagi dan menyimpan foto hasil

Foto hasil analisis hanya keluar dari aplikasi bila Anda sendiri menekan Simpan (foto disimpan ke galeri perangkat) atau Bagikan (Anda memilih aplikasi tujuan, misalnya WhatsApp). Setelah dibagikan, foto tunduk pada kebijakan aplikasi tujuan yang Anda pilih.

6. Yang tidak kami lakukan

  • Tidak mengumpulkan data pribadi ke server kami; aplikasi ini tidak memiliki server.
  • Tidak menjual atau membagikan data kepada pihak ketiga.
  • Tidak menampilkan iklan dan tidak memakai layanan analitik atau pelacakan.
  • Tidak melacak lokasi di latar belakang.

7. Keamanan

Data disimpan di area penyimpanan khusus aplikasi yang tidak dapat dibaca oleh aplikasi lain. PIN dan kode pemulihan disimpan sebagai hash dan dilengkapi jeda setelah beberapa kali salah memasukkan. Perlindungan ini ditujukan terhadap orang yang meminjam perangkat; jaga juga kunci layar perangkat Anda.

8. Menghapus data

  • Akun → Hapus akun dari HP ini menghapus nama, nomor HP, data kebun, PIN, kode pemulihan, catatan perawatan, dan data cuaca.
  • Riwayat pemeriksaan dapat dihapus satu per satu dari layar hasil pemeriksaan.
  • Menghapus instalasi aplikasi menghapus seluruh data aplikasi dari perangkat. Foto yang sebelumnya Anda simpan ke galeri tetap ada sampai Anda menghapusnya sendiri.

Karena kami tidak menyimpan salinan data Anda, tidak ada data yang perlu diminta untuk dihapus dari pihak kami.

9. Anak-anak

Aplikasi ini ditujukan bagi petani dan petugas pertanian dewasa, dan tidak ditujukan untuk anak-anak.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui bila fitur aplikasi berubah. Versi terbaru selalu tersedia di halaman ini, dengan tanggal berlaku di bagian atas.
